# Seguridad

Este repositorio es público. No contiene claves, tokens ni datos personales y no debe contenerlos nunca.

## Cómo informar de un problema

Usa "Report a vulnerability" en la pestaña Security del repositorio (informe privado). Evita abrir un issue público con detalles de una vulnerabilidad o con credenciales.

## Si se sube un secreto por error

1. Rota o revoca la clave de inmediato; borrar el commit no basta porque el repositorio es público.
2. Avisa por el canal privado anterior.
